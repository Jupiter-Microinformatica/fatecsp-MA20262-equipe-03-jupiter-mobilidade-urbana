# Projeto Prático: Mobilidade urbana (Microinformática Aplicada)

Projeto evolutivo de dados desenvolvido para a disciplina de Microinformática Aplicada (ILP590) - Fatec São Paulo. 
O objetivo deste repositório é consolidar, tratar e modelar dados do tema **[Seu Tema]** para a construção de indicadores de performance.

## 📁 Estrutura da Entrega Parcial

O projeto está dividido em etapas incrementais, cada uma com sua respectiva pasta e documentação detalhada:

* **[01-excel](./01-excel/):** Contém a Etapa 1. Planilha original tratada com funções avançadas, formatação condicional, de-paras e aba de auditoria.
* **[02-powerquery](./02-powerquery/):** Contém a Etapa 2. Automatização da limpeza de dados das filiais usando Power Query, exportação dos dados limpos (.csv) e scripts de tratamento estruturados.
* **[03-powerpivot](./03-powerpivot/):** Contém a Etapa 3. Construção do modelo relacional (Star Schema), tabela dCalendario, e as primeiras medidas em DAX validadas em Tabela Dinâmica.

Cada pasta contém um `README.md` específico com as instruções de execução, as regras de negócio aplicadas e as pendências identificadas em cada etapa.
